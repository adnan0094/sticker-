# نسخة PWA لمنبه الدواء

هذه الحزمة تحوّل التطبيق إلى تطبيق ويب قابل للتثبيت والعمل دون اتصال. افتح `index.html` عبر HTTPS أو `localhost` ثم اختر **إضافة إلى الشاشة الرئيسية**.

## الإشعارات بعد إغلاق التطبيق

تم تجهيز `sw.js` لاستقبال إشعارات Web Push حتى بعد إغلاق التطبيق. لكن إرسال الإشعار في الموعد يحتاج خادمًا صغيرًا يحتفظ باشتراك الجهاز ويرسل Push في وقت المنبه. لا يستطيع المتصفح وحده ضمان تشغيل مؤقت بعد إغلاق الصفحة بالكامل.

الموجود حاليًا:

- التثبيت كتطبيق مستقل.
- التخزين المحلي للإعدادات والنغمة.
- العمل دون اتصال بعد أول فتح.
- استقبال إشعارات Push عند ربط خادم إرسال.
- فتح التطبيق عند الضغط على الإشعار.

للاستخدام الحقيقي بعد الإغلاق، يلزم إضافة خادم Push مع مفتاح VAPID وجدولة المنبهات على الخادم.
